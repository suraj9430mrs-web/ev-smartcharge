Slot Assignment Engine

Trigger C++ assignment logic: sequential scan across speed-sorted stations.

Assign Charging Slot to Vehicle
Assignment Principle:
1. The C++ engine checks whether any vehicle is already waiting in the FIFO queue (guarantees fairness).
2. Searches for the highest speed compatible available station.
3. Calculates charging duration: Time (mins) = (Required Energy / Speed) × 60.
4. Marks station occupied and logs assignment to the Action Stack.

Queue Bug Correction & Compaction Note:

In the original team code, removing an element from the queue used absolute index shifts. Our refactored C++ Queue<T> implementation preserves this intended behavior while enforcing automated index compaction (resetting front to 0 when rear reaches bounds), ensuring zero memory leaks or index boundary faults.
